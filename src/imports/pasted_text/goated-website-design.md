GOATED Clothing Brand Website – Figma Make Prompt

Design a modern, premium desktop website for a clothing brand called GOATED.

The website should feel more like a premium fashion showroom or collection catalog than a traditional e-commerce website. The primary goal is to showcase the clothing collections beautifully and make it incredibly easy for customers to browse products and place an order.

Do not make it look like Amazon, Shein, or a marketplace. Instead, take inspiration from minimalist fashion brands and editorial lookbooks. The interface should be clean, refined, and focused on the clothing.

Design Style

The overall aesthetic should be:

Premium
Minimal
Modern
Editorial-inspired
Fashion-focused
Clean
Elegant
Easy to navigate

Avoid excessive animations, flashy effects, glassmorphism, or overly futuristic UI.

Use:

Black, white, charcoal, soft gray, and neutral tones
Plenty of whitespace
Large product photography
Premium typography (Inter, General Sans, Satoshi, or similar)
Subtle rounded corners
Soft shadows only where appropriate
Smooth hover states and subtle page transitions

The brand name GOATED should be featured consistently throughout the website, especially in the navigation and branding.

Navigation

Keep navigation minimal and intuitive.

Top Navigation:

GOATED (Logo)
Collections
Latest Drops
Shop
Cart
Search

No About page.

No Blog.

No unnecessary company information.

Everything should revolve around discovering the clothing.

Landing Page

Keep the landing page clean and focused.

The first section should feature a large, premium hero banner introducing the latest GOATED collection.

Below the hero, include only:

Latest Drops

Display the newest clothing releases in a clean product grid.

Collections

Show all available collections as large image cards that customers can click to browse.

Examples:

GOATED Essentials
Summer Collection
Oversized Collection
Limited Drop
Streetwear Series

Do not add sections like "Trending," "Best Sellers," "Featured Products," or promotional banners. The landing page should feel calm, organized, and fashion-focused.

Product Display

This is the most important section.

Products should be displayed in a spacious, minimalist grid.

Each product card should include:

Product name
Price
Available colors
Available sizes
Quick Order button

Every product must display three images using a smooth image slider or carousel:

Front view
Back view
Model/mannequin wearing the item

The image gallery should be the main visual element of each product card, with smooth transitions between views.

Product Details

Each product page should include:

Large image gallery (Front, Back, Model/Mannequin)
Product name
Price
Short description
Fabric/material details
Available colors
Size selector
Quantity selector
Stock availability
Delivery information
Add to Cart
Order Now

Maintain generous spacing and a premium editorial layout.

Ordering Experience

Keep the purchasing process straightforward.

Customers should:

Browse products
Choose a color
Choose a size
Select quantity
Add to cart or order immediately
Complete payment
Receive an order confirmation

The experience should be fast and uncomplicated.

Checkout

Collect only essential details:

Full Name
Phone Number
Email (optional)
Delivery Address

Supported payment methods:

Visa
Mastercard
MTN Mobile Money (Rwanda)

The payment section should feel secure, modern, and easy to understand.

Cart

The cart should display:

Product image
Selected color
Selected size
Quantity
Price
Total

Include only:

Continue Shopping
Proceed to Payment

Keep the layout simple.

Search

Provide a clean search bar with instant product suggestions.

Admin Portal

Design a separate admin dashboard.

The administrator should be able to:

Products
Add products
Edit products
Delete products
Upload exactly three images:
Front view
Back view
Model/Mannequin view
Set prices
Add available colors
Add available sizes
Manage stock quantities
Write product descriptions
Publish or hide products
Collections
Create collections
Edit collections
Archive collections
Upload collection cover images
Orders
View all orders
Update order status
Track payments
Inventory
Monitor stock
Receive low-stock alerts
Dashboard

Display:

Total products
Active orders
Revenue
Low stock items
Recent orders

Keep charts simple and unobtrusive.

Footer

A minimal footer with:

GOATED logo
Shipping Information
Returns
Contact
Instagram
TikTok
Overall Experience

The website should feel like visiting the online showroom of a premium clothing brand rather than a conventional online store.

The focus should always remain on:

High-quality product photography
Beautiful typography
Spacious layouts
Effortless navigation
A simple and trustworthy ordering process

Every design decision should reinforce GOATED's premium identity. The final result should be realistic, elegant, production-ready, and centered on showcasing clothing through clean layouts and a refined shopping experience.
